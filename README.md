# 🎨 Color Swap  

An endless runner game where the player matches their color with approaching tiles to survive.  
Features dynamic color swapping, progressive difficulty, and smooth gameplay.  

---

## 🚀 Play the Game  
👉 [Play Color Swap on itch.io](https://pradeep-09.itch.io/color-swap)  

---

## 🎮 Gameplay  
- Tap / Click to **swap your color**.  
- Pass through tiles that **match your current color**.  
- Survive as long as possible and beat your high score!  

---

## ✨ Features  
- Simple one-tap controls  
- Addictive and fast-paced gameplay  
- Smooth transitions and vibrant design  
- Endless mode with progressive difficulty
